LENDNEST FULL-STACK LOCAL APP (FREE STARTER)

What this includes:
- Responsive browser frontend
- Node.js backend using built-in modules (no npm packages needed)
- Listings API and persistent JSON storage
- Booking creation, IDs, demo pickup code and booking history
- Search/category filtering and add-listing form

REQUIREMENT:
- Install Node.js LTS on Windows from https://nodejs.org/ if it is not installed.
- Internet is only needed to download/install Node.js, not to use the app locally.

RUN:
1. Extract this ZIP to a normal folder (not inside the ZIP preview).
2. Double-click RUN_LENDNEST.bat.
3. A browser should open at http://localhost:3000.
4. Keep the black terminal window open while using the app.
5. To stop it, click the terminal window and press Ctrl+C.

DATA:
- data/items.json stores listings.
- data/bookings.json stores demo bookings.
Back up the data folder if you want to keep your local prototype data.

IMPORTANT LIMITS:
- This is a local prototype on one computer, not a public internet app.
- It has no user login or account security.
- It does not collect real payments or connect to UPI.
- The pickup code is a demo and does not unlock a physical locker.
- Do not enter sensitive personal information.
- Before real users or public launch, add authentication, authorization, security review, input/rate limiting, secure payment-provider integration, and real locker controller integration.
